# Lost and Found App

## Description
The Lost and Found App is an Android mobile application designed to connect lost items to their rightful owners. Users can easily report lost or found items by posting relevant information, helping items find their way back to where they belong.

## Key Features
* **Create Listings:** Users can post detailed adverts for lost or found items.
* **Image Upload:** Requires and supports image attachments for each item post.
* **Date/Time Stamping:** Automatically adds a timestamp to each posting so users can see how recent the listing is.
* **Search & Filter:** Includes functionality to filter lost and found items by specific categories (e.g., Electronics, Pets, Wallets).
* **Manage Listings:** Users can remove an advert from the database once the owner is found.

## Technologies Used
* **Language:** Java
* **IDE:** Android Studio
* **Database:** SQLite (Local storage)
* **Minimum SDK:** API 24 (Android 7.0 Nougat)

## How to Run
1. Clone or download this repository.
2. Open the project folder in Android Studio.
3. Sync the project with Gradle files.
4. Run the app on an Android Emulator or physical device running API 24 or higher
